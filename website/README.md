# Ramble website

The marketing site and docs at [ramble.watch](https://ramble.watch): a Next.js static export (`output: "export"`) deployed on Vercel from this folder, with a preview deployment for every PR that touches it.

```bash
npm install
npm run dev      # Dev server at localhost:3000
npm run build    # Static export to out/
```

Conventions for working on the site are in `CLAUDE.md` and `AGENTS.md`.
