# Ramble for Claude

Talk to your Apple Watch or iPhone. Ramble transcribes the note and holds it for your agent.

This plugin adds:

- **The Ramble connector** (`https://api.ramble.watch/mcp`): `list_new_notes`, `get_note` and `mark_handled`.
- **The `ramble-notes` skill**: how to work through new notes, act on each one, and mark it handled so nothing is done twice.

## Set up

1. Install Ramble from the App Store and open it on your iPhone.
2. Add this plugin, then connect the Ramble connector.
3. When the sign-in page asks, paste the pairing code from Ramble: Settings → Your agent → Connect.

Then ask Claude "check my Ramble notes", or set up a scheduled task that does it.
